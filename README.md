# Minecraft Jump Enchantment Plugin

Jumpbound Enchants is a Minecraft plugin that adds a random applicable enchantment to the item in a player’s main hand when they jump. It selects from registered enchantments that can enchant the held item, increases the selected enchantment’s level by one, and sends the player a message with the result.

## Install

1. Build the project with Java 21 and Maven: `mvn package`.
2. Copy the generated `target/plugin.jar` into your Minecraft server’s `plugins` directory.
3. Start or restart the server.

## Use

1. Hold an item that can be enchanted in your main hand.
2. Jump while on the ground.
3. The plugin randomly selects an enchantment applicable to the held item, adds it or increases its level by one, and displays the enchantment name and level in chat.
